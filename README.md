# 🛒 RedStore - Professional E-Commerce Web Application

A modern, responsive, corporate-grade e-commerce web application designed with an emphasis on sleek UI/UX, seamless navigation, and modular architecture. 

---

## ✨ Key Features

* **Responsive Corporate Design**: Fully optimized layout that adapts smoothly across mobile devices, tablets, and desktop screens.
* **Dynamic Product Sorting & Filtering**: Real-time live search functionality and instant product price sorting (*Low to High*, *High to Low*).
* **Interactive User Authentication**: Seamless tab switching between secure Login and Enterprise Registration forms.
* **Modular Codebase**: Clean and organized separation of concerns across multiple HTML pages, centralized styling (`style.css`), and interactive scripting (`script.js`).
* **Detailed Product Views**: Dynamic gallery loading and sizing options via URL query parameters.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Flexbox, Gradients, Custom Responsive Media Queries)
* **Scripting**: Vanilla JavaScript (ES6+)
* **Icons & Fonts**: FontAwesome v6.6.0, Google Fonts (Poppins)
